# Mithra Expenses Tracker

Responsive personal expense tracker with:
- Daily and monthly expenses
- Month-wise salary
- EMI tracking
- Loan tracking
- Reports and CSV export
- Full JSON backup
- Dark/light theme
- Currency setting
- LocalStorage persistence
- Responsive mobile/desktop UI
- 3D-style finance branding

## Run
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Open the generated GitHub Pages URL.

Data is stored locally in the browser; GitHub stores the app code, not your personal finance records.
